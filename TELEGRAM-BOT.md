# Telegram-бот «Аманда Север · заявки»: запуск за 10 минут

Файл для вас. Лежит в корне репозитория, а не в `public/`, поэтому на сайте его не видно.

## Как это работает
Форма на сайте → `/api/lead` (капча, проверка) → база заявок Cloudflare D1 → **мгновенное уведомление в бота** всем сотрудникам с кнопкой «✋ Взять в работу».
Копия каждой заявки по-прежнему сохраняется на Яндекс Диск (пока задан `YADISK_TOKEN`): это и есть то, что написано в политике.

Что умеет бот: меню со счётчиками · списки по статусам (🆕 Новая → 🔥 В работе → 📄 КП отправлено → ✅ Продано / ❌ Отказ) ·
карточка заявки с историей · заметки · передача заявки коллеге · кнопка WhatsApp · поиск по номеру, имени, телефону · сводка с графиком за 7 дней, конверсией и временем реакции ·
⏰ метка у заявок, которые ждут больше 2 часов · команда с приглашениями по ссылке · выгрузка CSV (только администратор).

## Шаги
1. **Бот.** В Telegram откройте @BotFather → `/newbot` → имя и username. Сохраните токен.
2. **Ваш ID.** Напишите @userinfobot: он пришлёт число (ваш Telegram ID). Если админов несколько, соберите все ID.
3. **База.** Cloudflare → Storage & Databases → D1 → Create database (имя любое, например `amanda-leads`). Таблицы бот создаст сам.
4. **Привязка базы.** Pages → ваш проект → Settings → Bindings → Add → D1 database → имя переменной строго `DB` → выберите созданную базу.
5. **Секреты** (Settings → Variables and Secrets, Production, тип Secret):
   - `TG_BOT_TOKEN`: токен из шага 1
   - `TG_WEBHOOK_SECRET`: придумайте длинную строку из латинских букв, цифр, `_` и `-` (20–40 знаков)
   - `TG_ADMIN_IDS`: ваш ID (несколько через запятую)
6. **Деплой.** Проект подключён к GitHub: любое изменение в репозитории выкладывается само. После добавления секретов и базы нажмите Deployments → Retry deployment (или сделайте любой коммит).
7. **Включите бота.** Откройте в браузере один раз: `https://ВАШ-ДОМЕН/api/tg?key=<значение TG_WEBHOOK_SECRET>`
   Должно прийти `{"webhook":true,"commands":true,"bot":"@...","database":true,...}`.
8. **Старт.** Откройте бота в Telegram и нажмите «Старт»: появится панель. Администраторы должны нажать «Старт» хотя бы раз, иначе бот не сможет им писать.
9. **Менеджеры.** В боте: «👥 Команда» → «➕ Пригласить менеджера» → отправьте ссылку сотруднику. Ссылка живёт 48 часов и работает один раз.
10. **Тест.** Отправьте заявку с сайта: через секунду она придёт в бота.

## Важно
- Если `DB` не привязана, заявки по-прежнему сохраняются на Яндекс Диск, а в бота не приходят. Панель работает только с базой.
- Заявки в базе и на Диске удаляются через 2,5 года автоматически. Сообщения в Telegram чистятся вручную, это отмечено в политике.
- Кнопка «🗑 Удалить» убирает заявку только из бота; копия на Диске остаётся (нужно для запросов на удаление данных: удаляйте и там).
- Сменили токен бота: обновите `TG_BOT_TOKEN` и снова откройте ссылку из шага 7.
