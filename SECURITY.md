# Запуск сайта: безопасная настройка (Cloudflare Pages)

Файл README для вас, на сервер его выкладывать не нужно (при загрузке папки удалите `SECURITY.md` и `TELEGRAM-BOT.md`).

## 0. Что внутри
- `index.html` — сайт (без внешних сервисов: нет Google Fonts, трекеров и сторонних скриптов, кроме невидимой капчи Cloudflare Turnstile)
- `_headers` — заголовки безопасности (CSP, HSTS и др.)
- `functions/api/lead.js` — приём заявок: проверка капчи и данных, база D1, уведомление в Telegram, копия на Яндекс Диск
- `functions/api/tg.js`, `functions/_lib/` — Telegram-бот: панель менеджера
- `.well-known/security.txt`, `robots.txt`

## 1. Аккаунты и домен (самое важное)
1. Включите **2FA (приложение-аутентификатор)** у регистратора домена, в Cloudflare и в почте `amandasever@yandex.ru`. Захват аккаунта опаснее любого DDoS.
2. У регистратора включите **Registrar Lock** и автопродление.
3. Пароли: уникальные, в менеджере паролей.

## 2. Cloudflare Pages
1. Workers & Pages → Create → Pages → **Direct Upload** → загрузите папку (с `functions/`, `_headers`, `.well-known/`).
   Если Direct Upload не подхватывает `functions/`, используйте деплой из GitHub или `npx wrangler pages deploy .`
2. Custom domains → добавьте `домен.com` и `www.домен.com`.
3. DNS: перенесите домен на Cloudflare (смена nameservers у регистратора) и включите **DNSSEC** (DNS → Settings).

## 3. Заявки: Яндекс Диск + невидимая капча
Путь заявки: форма на сайте → ваша функция `/api/lead` (проверка капчи Turnstile, согласия, формата) → Яндекс Диск (серверы в РФ).
Ключ доступа к Диску хранится только на сервере, в браузер он не попадает.

**Почему не «Яндекс Таблица»:** у файлов Яндекс Таблиц нет API, дописать в них строку с сайта нельзя. Поэтому заявки сохраняются так:
- каждая заявка — отдельный файл `Заявки/2026-10-17_1913_AS-XXXXXX.csv` (надёжно: ничего не затирается);
- плюс общий файл `Заявки/Заявки.csv`: одна строка на заявку, его открывают как таблицу (Яндекс Таблицы, Excel; разделитель — точка с запятой, кодировка UTF-8).
Если у вас появится организация Яндекс 360 для бизнеса, можно перейти на Яндекс Формы с автоматической таблицей ответов, скажите, и я перепишу.

### 3.1. Токен Яндекс Диска (один раз, под аккаунтом, где лежит Диск)
1. Откройте https://oauth.yandex.ru/client/new → название любое (например, «Заявки сайта»), платформа «Веб-сервисы», Callback URL: `https://oauth.yandex.ru/verification_code`.
2. В разделе «Доступ к данным» добавьте **Яндекс Диск REST API → Доступ к папке приложения** (`cloud_api:disk.app_folder`). Не давайте полный доступ к Диску: с этим правом ключ видит только свою папку.
3. Сохраните, скопируйте **ID приложения** и откройте в браузере (под нужным аккаунтом):
   `https://oauth.yandex.ru/authorize?response_type=token&client_id=<ID приложения>`
   Нажмите «Разрешить» и скопируйте полученный токен. Токен имеет срок действия (обычно до года): поставьте напоминание, по истечении повторите шаг 3 и обновите секрет.
4. Включите 2FA на этом аккаунте Яндекса. Папка с заявками появится на Диске сама: «Приложения → <название приложения> → Заявки». Общий доступ по ссылке к ней не включайте.

### 3.2. Капча Turnstile
Cloudflare → Turnstile → Add site (домен сайта, режим **Managed**) → получите **Site key** и **Secret key**.
В `index.html` найдите `window.TURNSTILE_SITEKEY = '';` и вставьте **Site key** (публичный). Капча невидимая: обычный посетитель ничего не видит, окошко появляется только если проверка сомневается.
Без секрета Turnstile функция заявки НЕ принимает (защита не отключается молча).

### 3.3. Секреты Cloudflare
Pages → проект → Settings → Variables and Secrets (Production), добавьте как **Secret**:
- `TURNSTILE_SECRET` — секретный ключ Turnstile
- `YADISK_TOKEN` — токен из п. 3.1
- `ALLOWED_ORIGINS` — `https://домен.com,https://www.домен.com`
- Telegram-бот с панелью менеджера: `TG_BOT_TOKEN`, `TG_WEBHOOK_SECRET`, `TG_ADMIN_IDS` и база D1 с именем привязки `DB`. Пошаговая инструкция в файле `TELEGRAM-BOT.md`. Яндекс Диск остаётся архивом-копией, пока задан `YADISK_TOKEN`. Telegram и Cloudflare D1 уже добавлены в политику (`#/privacy`, раздел 4).
- `TG_CHAT_ID` — необязательный запасной чат: если база недоступна, полная заявка уйдёт туда.
Передеплойте и отправьте тестовую заявку: через несколько секунд она должна появиться в папке на Диске.

### Подключение CRM (позже)
Задайте `FORWARD_URL` и `FORWARD_TOKEN` (вебхук CRM): функция уже умеет слать туда JSON. Формат у каждой CRM свой — подгоним `functions/api/lead.js` под выбранную.

## 4. Защита от DDoS и ботов (Cloudflare → ваш домен)
- SSL/TLS → режим **Full (strict)**; Edge Certificates → **Always Use HTTPS**, **Min TLS 1.2**, **HSTS** (если включаете здесь, уберите дубль из `_headers`).
- Security → **Bot Fight Mode: On**.
- Security → WAF → **Rate limiting rules** → Create:
  - если URI Path = `/api/lead` и Method = POST
  - 5 запросов за 1 минуту с одного IP → Block на 10 минут.
- Security → WAF → Managed rules: включите бесплатный набор (Cloudflare Free Managed Ruleset).
- Security → Settings → Security Level: Medium (при атаке временно «Under Attack Mode»).
- Страны: если клиенты только из РФ/СНГ, можно добавить правило «Managed Challenge» для остальных стран. Это необязательно, но снижает мусор.

## 5. Почта (чтобы с вашего домена не рассылали подделки)
Если заведёте почту на домене, добавьте в DNS записи SPF, DKIM (даёт почтовый сервис) и DMARC:
`_dmarc  TXT  "v=DMARC1; p=quarantine; rua=mailto:amandasever@yandex.ru"`
Также добавьте CAA-запись: `0 issue "letsencrypt.org"` и `0 issue "pki.goog"` (Cloudflare выпускает сертификаты через них).

## 6. Закон (152-ФЗ): сделайте до запуска
- Политика конфиденциальности (`#/privacy`) заполнена: сервисы (Cloudflare, Turnstile, Яндекс Диск) и срок хранения 2,5 года. Если измените состав сервисов или срок, поправьте раздел 4 политики.
- Подайте **уведомление об обработке персональных данных в Роскомнадзор** (pd.rkn.gov.ru).
- Заявки хранятся на Яндекс Диске (РФ). Но перед записью на Диск данные проходят через сервер Cloudflare (оператор за рубежом), а Telegram (если включите) тоже зарубежный. Строгое чтение закона требует, чтобы первичная запись шла на серверы в РФ. Это правовой вопрос, покажите схему юристу. Если нужно строго: запускайте приём заявок на российском сервере (например, Yandex Cloud Functions), скажите, и я перенесу `lead.js`.
- Срок 2,5 года: удаление срабатывает при поступлении новых заявок (после каждой заявки удаляются файлы и строки старше срока). Если заявок долго нет, раз в месяц проверяйте папку и удаляйте старое вручную. Удалённое попадает в корзину Диска, периодически очищайте её.

## 7. Регулярно
- Раз в квартал меняйте токен бота (@BotFather → /revoke) и обновляйте секрет.
- Смотрите Security → Events в Cloudflare: видно, кого блокирует защита.
- Не вставляйте в `index.html` пароли и ключи, кроме публичного Site key.
